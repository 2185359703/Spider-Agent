# AI 招聘采集接入平台

输入招聘入口 URL，由 AI 分析网站、开发采集器、验证并汇报，自动生成候选提交；人工运行、人工审查后采纳，有问题则进入 AI 纠错。

当前交付为开发设计文档，尚未实现应用、部署服务或生成 Git 提交。
